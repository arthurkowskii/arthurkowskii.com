# what's broken in the mobile version
1. the header
    right now the header is messed up because too much button for a mobile device. The plan is to move the filter buttons on the bottom of the page so it's easy to acces for a mobile user. the dark mode should not be visible at all because the website should addapt to the mobile settings for dark and light mode.
2. the previews
    the previews in the desktop website are triggered by hovering, so not possible for a mobile device so the preview workflow should be recreated like this : clicking on an electron always trigger the preview, not the project page, and if the user click on the preview after that then it open the related page. the bio page however is the only page that opens directly because there is no preview.
3. the bento
    the bento is great except for the hero card. on mobile the hero card is almost fully hidden by the hero description. The solution would be to move the hero description to it's own card and leave the hero image/videos on it's own too.
